Nunca houve melhor altura para aderir ao XMPP, uma rede pública e gratuita de conversação que ninguém controla nem possui. O Monal é uma forma rápida e fácil de utilizar o XMPP. Basta descarregar a aplicação, iniciar sessão ou registar-se e estará pronto para conversar em poucos minutos. Tem o aspeto e funciona como as outras aplicações, por isso não é necessário «aprender XMPP» nem sequer preocupar-se com o que é.

Funcionalidades de destaque:
-Código aberto
-Sem anúncios! Forte enfoque na privacidade. Não comunica com servidores externos sem necessidade e não possui «métricas» de utilização do software.
-Não lê quaisquer informações pessoais
-Com uma ligação direta ao seu servidor, a sua palavra-passe e todas as outras informações nunca são enviadas para terceiros
-Conversas encriptadas com OMEMO
-Funciona com servidores XMPP empresariais que requerem VPN
-Suporte para conversas multiutilizador (MUC) em grupos
-Chamadas de áudio/vídeo

Implementa determinadas extensões XMPP destinadas a melhorar a comunicação em dispositivos móveis:
-XEP-0357: Notificações push
-XEP-0280: Message Carbons, que mantêm as mensagens sincronizadas entre clientes
-XEP-0198: Stream Management, para restabelecer rapidamente a ligação
-XEP-0199: XMPP Ping, para manter as ligações
-XEP-0313: Message Archive Management, para descarregar o histórico das conversas
-XEP-0352: Client State Indication, para reduzir drasticamente o consumo de energia
-XEP-0363: HTTP File Upload, para enviar imagens nas conversas
