Nunca houve um momento melhor para começar a usar o XMPP, uma rede pública de bate-papo livre que ninguém controla nem possui. O Monal é uma forma rápida e fácil de usar o XMPP. Basta baixar o aplicativo, fazer login ou criar uma conta e, em poucos minutos, você estará pronto para conversar. A aparência e o funcionamento são semelhantes aos de outros aplicativos, portanto não é necessário «aprender XMPP» nem mesmo saber o que ele é.

Implementa diversas extensões do XMPP desenvolvidas para melhorar a comunicação em dispositivos móveis:
XEP-0357: Notificações push.
XEP-0280: Message Carbons, para manter as mensagens sincronizadas entre clientes.
XEP-0198: Stream Management, para reconexão rápida.
XEP-0199: XMPP Ping, para manter as conexões ativas.
XEP-0313: Message Archive Management, para baixar o histórico das conversas.
XEP-0352: Client State Indication, para reduzir drasticamente o consumo de energia.
XEP-0363: Envio de arquivos, para enviar imagens nas conversas
