XMPPを始めるのに、これほど良い時期はかつてありません。XMPPは、誰も管理・所有していない無料の公開チャットネットワークです。Monalは、XMPPを利用するための高速で使いやすいアプリです。アプリをダウンロードし、ログインまたは登録するだけで、数分以内にチャットを始めることができます。他のチャットアプリと同じような見た目と操作性を備えているため、「XMPPを学ぶ」必要も、XMPPが何であるかを気にする必要もありません。

主な機能:
オープンソース
広告なし！プライバシーを最優先しています。外部への情報送信（ホームへの通信）を行わず、ソフトウェアの「利用状況メトリクス」も収集しません。
個人情報を読み取りません。
サーバーへ直接接続するため、パスワードやその他すべての情報が第三者に送信されることはありません。
OMEMOによる暗号化チャット
VPNを必要とする企業向けXMPPサーバーでも利用できます。
グループチャット用のマルチユーザーチャット（MUC）対応
音声・ビデオ通話

モバイル通信を改善するための一部のXMPP拡張機能を実装しています:
XEP-0357: プッシュ通知
XEP-0280: Message Carbons（メッセージカーボン）による、複数クライアント間でのメッセージ同期
XEP-0198: Stream Management（ストリーム管理）による高速な再接続
XEP-0199: XMPP Pingによる接続維持
XEP-0313: Message Archive Management（メッセージアーカイブ管理）によるチャット履歴の取得
XEP-0352: Client State Indication（クライアント状態通知）による消費電力の大幅な削減
XEP-0363: HTTP File Upload（HTTPファイルアップロード）による会話中の画像送信
