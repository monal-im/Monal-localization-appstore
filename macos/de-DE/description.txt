Noch nie war ein besserer Zeitpunkt, um in XMPP einzusteigen, einem kostenlosen öffentlichen Chat-Netzwerk, das niemand kontrolliert oder besitzt. Monal ist eine schnelle und benutzerfreundliche Möglichkeit, XMPP zu nutzen. Laden Sie einfach die App herunter, melden Sie sich an oder registrieren Sie sich, und schon können Sie innerhalb weniger Minuten chatten. Die App sieht aus und funktioniert so, wie Sie es von anderen Apps gewohnt sind, sodass Sie weder „XMPP lernen“ noch sich darum kümmern müssen, was es überhaupt ist.

Bemerkenswerte Funktionen:
-Open Source
-Keine Werbung! Starker Fokus auf Datenschutz. Es werden keine Daten nach Hause gesendet und es gibt keine Software-„Metriken“
-Liest keine persönlichen Informationen aus
-Durch eine direkte Verbindung zu Ihrem Server werden Ihr Passwort und alle anderen Informationen niemals an Dritte gesendet
-OMEMO-verschlüsselter Chat
-Funktioniert auch mit Unternehmens-XMPP-Servern, die ein VPN erfordern
-Unterstützung für Multi-User-Chats (MUC) für Gruppenchats
-Audio-/Videoanrufe

Implementiert bestimmte XMPP-Erweiterungen zur Verbesserung der mobilen Kommunikation:
-XEP-0357: Push-Benachrichtigungen
-XEP-0280: Message Carbons halten Nachrichten zwischen Clients synchron
-XEP-0198: Stream Management für eine schnelle Wiederverbindung
-XEP-0199: XMPP Ping zum Aufrechterhalten von Verbindungen
-XEP-0313: Message Archive Management zum Herunterladen des Chatverlaufs
-XEP-0352: Client State Indication zur drastischen Reduzierung des Stromverbrauchs
-XEP-0363: HTTP File Upload zum Senden von Bildern in Unterhaltungen
