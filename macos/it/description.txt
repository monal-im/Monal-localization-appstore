Non c'è mai stato momento migliore per avvicinarsi a XMPP, una rete di chat pubblica e libera che nessuno controlla né possiede. Monal è un modo rapido e intuitivo per usare XMPP. Basta scaricare l'app, accedere o registrarsi e in pochi minuti sei pronto per chattare. Ha l'aspetto e il funzionamento delle altre app, quindi non c'è bisogno di «imparare XMPP» e nemmeno di preoccuparsi di cosa sia.

Funzionalità principali:
-Open Source
-Nessuna pubblicità! Grande attenzione alla privacy. Non comunica con server esterni e non raccoglie «metriche» sul software.
-Non legge alcuna informazione personale.
-Con una connessione diretta al tuo server, la tua password e tutte le altre informazioni non vengono mai inviate a terze parti.
-Chat crittografate con OMEMO.
-Funziona con server XMPP aziendali che richiedono una VPN.
-Supporto alle chat multiutente (MUC) per le conversazioni di gruppo.
-Chiamate audio/video.

Implementa alcune estensioni XMPP destinate a migliorare la comunicazione sui dispositivi mobili:
-XEP-0357: notifiche push
-XEP-0280: Message Carbons, per mantenere sincronizzati i messaggi tra i client
-XEP-0198: Stream Management, per riconnettersi rapidamente
-XEP-0199: XMPP Ping, per mantenere attive le connessioni
-XEP-0313: Message Archive Management, per scaricare la cronologia delle chat
-XEP-0352: Client State Indication, per ridurre drasticamente il consumo energetico
-XEP-0363: HTTP File Upload, per inviare immagini nelle conversazioni
