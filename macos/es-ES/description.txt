No hay mejor momento para empezar a usar XMPP, una red pública de chat gratuita que nadie controla ni posee. Monal es una forma rápida y fácil de usar XMPP. Solo descarga la aplicación, inicia sesión o regístrate y estarás listo para chatear en cuestión de minutos. Su aspecto y funcionamiento son similares a los de otras aplicaciones, por lo que no necesitas «aprender XMPP» ni siquiera preocuparte por qué es.

Características destacadas:
-Código abierto
-¡Sin anuncios! Gran enfoque en la privacidad. No se comunica con servidores externos y no recopila «métricas» de uso del software
-No lee ninguna información personal
-Con una conexión directa a tu servidor, tu contraseña y toda la demás información nunca se envían a terceros
-Chat cifrado con OMEMO
-Funciona con servidores XMPP corporativos que requieren VPN
-Compatibilidad con chats multiusuario (MUC) para chats grupales
-Llamadas de audio/vídeo

Implementa determinadas extensiones de XMPP destinadas a mejorar la comunicación móvil:
-XEP-0357: Notificaciones push
-XEP-0280: Message Carbons para mantener los mensajes sincronizados entre clientes
-XEP-0198: Gestión de flujo para volver a conectarse rápidamente
-XEP-0199: Ping de XMPP para mantener las conexiones
-XEP-0313: Gestión del archivo de mensajes para descargar el historial de chats
-XEP-0352: Indicación del estado del cliente para reducir drásticamente el consumo de energía
-XEP-0363: Carga de archivos mediante HTTP para enviar imágenes en las conversaciones
