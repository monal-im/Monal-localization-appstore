Quicksy ist eine Abspaltung des beliebten XMPP-Clients Monal mit automatischer Kontakterkennung.

Sie registrieren sich mit Ihrer Telefonnummer, und Quicksy schlägt Ihnen automatisch – basierend auf den Telefonnummern in Ihrem Adressbuch – mögliche Kontakte vor. Im Hintergrund ist Quicksy ein vollwertiger XMPP-Client, mit dem Sie mit jedem Benutzer auf jedem öffentlich föderierenden Server kommunizieren können. Ebenso können Quicksy-Benutzer von außen kontaktiert werden, indem Sie einfach +Telefonnummer@quicksy.im zu Ihrer Kontaktliste hinzufügen.

Abgesehen von der Kontaktsynchronisierung ist die Benutzeroberfläche bewusst so nah wie möglich an Monal gehalten. Dadurch können Benutzer später von Quicksy zu Monal wechseln, ohne sich erneut mit der Bedienung der App vertraut machen zu müssen.
