Es gab noch nie einen besseren Zeitpunkt, um mit XMPP zu beginnen, einem freien öffentlichen Chat-Netzwerk, das niemand kontrolliert oder besitzt. Monal ist eine schnelle und benutzerfreundliche Möglichkeit, XMPP zu verwenden. Laden Sie einfach die App herunter, melden Sie sich an oder registrieren Sie sich, und schon können Sie innerhalb weniger Minuten chatten. Es sieht aus und funktioniert wie andere Apps, daher müssen Sie „XMPP nicht lernen“ und müssen sich auch nicht darum kümmern, was es ist.

Wichtige Funktionen:
Open Source
Keine Werbung! Starker Fokus auf Datenschutz. Sendet keine Daten nach Hause und verfügt nicht über Software-„Metriken“.
Liest keine persönlichen Informationen.
Bei einer direkten Verbindung zu Ihrem Server werden Ihr Passwort und alle anderen Informationen niemals an Dritte gesendet.
Verschlüsselter Chat mit OMEMO.
Funktioniert mit Unternehmens-XMPP-Servern, die ein VPN erfordern.
Unterstützung für Mehrbenutzer-Chats (MUC) für Gruppenchats.
Audio-/Videoanrufe.

Implementiert bestimmte XMPP-Erweiterungen zur Verbesserung der mobilen Kommunikation:
XEP-0357: Push-Benachrichtigungen.
XEP-0280: Message Carbons hält Nachrichten zwischen Clients synchron.
XEP-0198: Stream Management für eine schnelle Wiederverbindung.
XEP-0199: XMPP Ping zur Aufrechterhaltung von Verbindungen.
XEP-0313: Message Archive Management zum Herunterladen des Chatverlaufs.
XEP-0352: Client State Indication für eine deutliche Reduzierung des Energieverbrauchs.
XEP-0363: HTTP File Upload zum Senden von Bildern in Gesprächen
