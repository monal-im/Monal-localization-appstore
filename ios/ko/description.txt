지금보다 XMPP를 시작하기에 더 좋은 때는 없습니다. XMPP는 누구도 통제하거나 소유하지 않는 자유로운 공개 채팅 네트워크입니다. Monal은 빠르고 사용하기 쉬운 XMPP 사용 방법을 제공합니다. 앱을 다운로드하고 로그인하거나 가입하기만 하면 몇 분 안에 채팅을 시작할 수 있습니다. 다른 앱과 같은 방식으로 보이고 작동하므로 «XMPP를 배울» 필요도 없고, 그것이 무엇인지 신경 쓸 필요도 없습니다.

주요 기능:
오픈 소스
광고 없음! 개인정보 보호에 중점을 둡니다. 개발자에게 데이터를 전송하지 않으며 소프트웨어 «통계 정보»를 수집하지 않습니다.
어떠한 개인정보도 읽지 않습니다.
서버에 직접 연결하면 비밀번호와 기타 모든 정보가 제3자에게 절대 전송되지 않습니다.
OMEMO 암호화 채팅
VPN이 필요한 기업용 XMPP 서버와 함께 작동
그룹 채팅을 위한 다중 사용자 채팅(MUC) 지원
음성/영상 통화

모바일 통신을 개선하기 위해 설계된 일부 XMPP 확장 기능을 구현합니다:
XEP-0357: 푸시 알림
XEP-0280: Message Carbons, 클라이언트 간 메시지를 동기화합니다.
XEP-0198: Stream Management, 빠른 재연결을 지원합니다.
XEP-0199: XMPP Ping, 연결을 유지합니다.
XEP-0313: Message Archive Management, 채팅 기록을 다운로드합니다.
XEP-0352: Client State Indication, 전력 사용량을 크게 줄입니다.
XEP-0363: 파일 업로드, 대화에서 이미지를 전송합니다
