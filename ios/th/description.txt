ไม่เคยมีช่วงเวลาใดที่เหมาะสมไปกว่านี้ในการเริ่มต้นใช้ XMPP ซึ่งเป็นเครือข่ายแชตสาธารณะฟรีที่ไม่มีใครควบคุมหรือเป็นเจ้าของ Monal เป็นวิธีที่รวดเร็วและใช้งานง่ายในการใช้ XMPP เพียงดาวน์โหลดแอป เข้าสู่ระบบหรือลงทะเบียน แล้วคุณก็พร้อมแชตได้ภายในไม่กี่นาที รูปลักษณ์และการทำงานเหมือนกับแอปอื่น ๆ ดังนั้นคุณไม่จำเป็นต้อง “เรียนรู้ XMPP” หรือแม้แต่ต้องสนใจว่ามันคืออะไร

รองรับส่วนขยาย XMPP บางรายการที่ออกแบบมาเพื่อปรับปรุงการสื่อสารบนอุปกรณ์เคลื่อนที่:
-XEP-0357: การแจ้งเตือนแบบ Push
-XEP-0280: Message Carbons ช่วยซิงค์ข้อความระหว่างไคลเอนต์ต่าง ๆ
-XEP-0198: Stream Management ช่วยให้เชื่อมต่อใหม่ได้อย่างรวดเร็ว
-XEP-0199: XMPP Ping ช่วยรักษาการเชื่อมต่อ
-XEP-0313: Message Archive Management สำหรับดาวน์โหลดประวัติการแชต
-XEP-0352: Client State Indication ช่วยลดการใช้พลังงานลงอย่างมาก
-XEP-0363: HTTP File Upload สำหรับส่งรูปภาพในการสนทนา
