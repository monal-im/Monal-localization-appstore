Nunca ha habido un mejor momento para comenzar a usar XMPP, una red pública de chat libre que nadie controla ni posee. Monal es una forma rápida y fácil de usar XMPP. Solo descarga la aplicación, inicia sesión o regístrate y en cuestión de minutos estarás listo para chatear. Se ve y funciona como otras aplicaciones, por lo que no necesitas «aprender XMPP» ni siquiera saber qué es.

Características principales:
-Código abierto.
-¡Sin anuncios! Gran enfoque en la privacidad. No envía información a sus desarrolladores ni recopila «métricas» del software.
-No lee información personal.
-Con una conexión directa a tu servidor, tu contraseña y toda tu información nunca se envían a terceros.
-Chat cifrado con OMEMO.
-Funciona con servidores XMPP empresariales que requieren una VPN.
-Compatibilidad con chat multiusuario (MUC) para conversaciones grupales.
-Llamadas de audio y video.

Implementa varias extensiones de XMPP diseñadas para mejorar la comunicación en dispositivos móviles:
-XEP-0357: Notificaciones push.
-XEP-0280: Message Carbons, para mantener los mensajes sincronizados entre clientes.
-XEP-0198: Stream Management, para una reconexión rápida.
-XEP-0199: XMPP Ping, para mantener las conexiones activas.
-XEP-0313: Message Archive Management, para descargar el historial de conversaciones.
-XEP-0352: Client State Indication, para reducir drásticamente el consumo de energía.
-XEP-0363: Carga de archivos, para enviar imágenes en las conversaciones
