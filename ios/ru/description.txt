Никогда ещё не было лучшего времени, чтобы начать пользоваться XMPP — бесплатной общедоступной сетью обмена сообщениями, которой никто не управляет и которой никто не владеет. Monal — быстрый и удобный способ использовать XMPP. Просто загрузите приложение, войдите в аккаунт или зарегистрируйтесь — и уже через несколько минут вы сможете общаться. Оно выглядит и работает так же, как другие приложения, поэтому вам не нужно «изучать XMPP» и даже знать, что это такое.

Основные возможности:
-Открытый исходный код
-Никакой рекламы! Особое внимание уделяется конфиденциальности. Приложение не отправляет данные разработчикам и не собирает программные «метрики».
-Не считывает никакую личную информацию
-При прямом подключении к вашему серверу ваш пароль и вся остальная информация никогда не передаются третьим сторонам
-Зашифрованные чаты с использованием OMEMO
-Работает с корпоративными XMPP-серверами, для доступа к которым требуется VPN
-Поддержка многопользовательских чатов (MUC) для групповых чатов
-Аудио- и видеозвонки

Поддерживаются следующие расширения XMPP, предназначенные для улучшения работы на мобильных устройствах:
-XEP-0357: Push-уведомления
-XEP-0280: Message Carbons для синхронизации сообщений между клиентами
-XEP-0198: управление потоком для быстрого переподключения
-XEP-0199: XMPP Ping для поддержания соединений
-XEP-0313: управление архивом сообщений для загрузки истории чатов
-XEP-0352: индикация состояния клиента для значительного снижения энергопотребления
-XEP-0363: загрузка файлов через HTTP для отправки изображений в чатах
