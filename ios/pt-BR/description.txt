Nunca houve melhor momento para começar a usar o XMPP, uma rede pública e gratuita de bate-papo que ninguém controla ou possui. O Monal é uma maneira rápida e fácil de usar o XMPP. Basta baixar o aplicativo, fazer login ou se registrar e você estará pronto para conversar em poucos minutos. Ele tem a aparência e funciona como os outros aplicativos, portanto, não é necessário “aprender XMPP” nem mesmo se preocupar com o que ele é.

Principais recursos:
-Código aberto
-Sem anúncios! Forte foco na privacidade. Não se comunica com servidores externos sem necessidade e não possui “métricas” de uso do software
-Não lê nenhuma informação pessoal
-Com uma conexão direta ao seu servidor, sua senha e todas as outras informações nunca são enviadas a terceiros
-Conversas criptografadas com OMEMO
-Funciona com servidores XMPP corporativos que exigem VPN
-Suporte a conversas multiusuário (MUC) para grupos
-Chamadas de áudio/vídeo

Implementa algumas extensões XMPP destinadas a melhorar a comunicação em dispositivos móveis:
-XEP-0357: Notificações push
-XEP-0280: Message Carbons, que mantêm as mensagens sincronizadas entre clientes
-XEP-0198: Stream Management, para reconectar rapidamente
-XEP-0199: XMPP Ping, para manter as conexões
-XEP-0313: Message Archive Management, para baixar o histórico de conversas
-XEP-0352: Client State Indication, para reduzir drasticamente o consumo de energia
-XEP-0363: HTTP File Upload, para enviar imagens nas conversas
